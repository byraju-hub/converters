# 설치 가이드 — Raju's Converters

내 PC에서 영상·PDF·이미지를 변환하는 프로그램입니다. 모든 변환은 **내 PC 안에서** 돌아가고 계정이나 요금이 필요 없습니다.
이 문서는 처음 받은 분이 막힘 없이 설치해서 쓰도록 단계별로 안내합니다.

## 한눈에 보기

1. **Python을 설치**합니다 (한 번만).
2. **프로그램을 받아 압축을 풉니다.**
3. 폴더 안의 **`setup.bat`을 더블클릭**합니다. (3~10분)
4. 바탕화면의 **Raju's Converters** 아이콘을 더블클릭하면 브라우저에서 열립니다.

## 준비물

| 항목 | 내용 |
|---|---|
| 운영체제 | **Windows 10 / 11** (설치 도우미 `setup.bat`이 Windows용입니다) |
| Python | 3.10 이상. **3.12~3.14를 권장**합니다. 개발자는 3.14에서 시험했고, 다른 버전은 확인하지 못했습니다. |
| 디스크 여유 | 약 **1.5GB 이상**. 프로그램 약 650MB와 처음 쓸 때 내려받는 모델이 더해집니다. |
| 인터넷 | 설치할 때와 처음 쓰는 기능의 모델을 받을 때 필요합니다. 유튜브 변환은 쓸 때마다 필요합니다. |
| 한컴오피스 (선택) | **한글(.hwp·.hwpx) 문서를 PDF·이미지로 바꾸려면** 필요합니다. 없어도 Markdown 변환은 됩니다. |
| 브라우저 | **Chrome 또는 Edge를 권장**합니다. 다른 브라우저에서도 열리지만 유리 질감의 굴절 효과는 Chrome 계열에서만 보입니다. |

## 단계별 설치

### 1단계. Python 설치

이미 Python 3.10 이상이 있다면 건너뛰세요. 확인하려면 명령 프롬프트(`cmd`)에서 `python --version`을 입력해 보세요.

1. <https://www.python.org/downloads/> 에서 **Download Python** 버튼으로 설치 파일을 받습니다.
2. 설치 파일을 실행하고, **첫 화면 아래의 "Add python.exe to PATH"를 반드시 체크**한 뒤 "Install Now"를 누릅니다.
3. 설치가 끝나면 열려 있는 명령 프롬프트나 폴더 창을 모두 닫습니다. (이미 열린 창은 새 설치를 인식하지 못합니다.)

### 2단계. 프로그램 받기

**방법 A — ZIP으로 받기 (git을 몰라도 됩니다)**

1. <https://github.com/byraju-hub/converters> 로 갑니다.
2. 초록색 **Code** 버튼 → **Download ZIP**을 누릅니다.
3. 받은 ZIP의 압축을 풉니다. 풀린 폴더(`converters-main`)를 원하는 곳에 두세요.

**방법 B — git으로 받기**

```
git clone https://github.com/byraju-hub/converters.git
```

> **폴더 위치 팁**
> - `C:\Users\내이름\converters` 처럼 **영문 경로**를 권장합니다. 일부 도구가 한글 경로에서 문제를 일으킨 사례가 있어서입니다. (직접 검증한 것은 아닙니다.)
> - `C:\Program Files` 아래나 OneDrive 동기화 폴더는 피하세요. 쓰기 권한 문제나 동기화 충돌이 생길 수 있습니다.

### 3단계. `setup.bat` 실행

폴더 안의 **`setup.bat`을 더블클릭**하세요. 검은 창이 열리고 다음을 자동으로 합니다.

| 순서 | 하는 일 |
|---|---|
| 1/5 | Python을 찾고 버전을 확인합니다. |
| 2/5 | 이 폴더 안에 전용 작업 공간(`.venv`)을 만듭니다. 다른 프로그램에 영향을 주지 않습니다. |
| 3/5 | 필요한 프로그램을 설치합니다. **약 650MB, 3~10분**이 걸리며 창이 멈춘 것처럼 보여도 닫지 마세요. |
| 4/5 | 제대로 설치됐는지 확인합니다. |
| 5/5 | 바탕화면에 바로가기를 만듭니다. |

중간에 두 가지를 물어봅니다. 엔터만 치면 기본값으로 진행됩니다.

- **"'서버 시작' 버튼을 쓰려면 등록이 필요해요…" (기본: 아니요)** — 필요 없다면 그냥 엔터를 치세요. 자세한 내용은 [선택 설정](#선택-설정)을 보세요.
- **"지금 바로 실행할까요?" (기본: 예)**

> **"Windows에서 PC를 보호했습니다" 화면이 뜨면**
> 인터넷에서 받은 파일에 Windows가 붙이는 경고입니다. **추가 정보 → 실행**을 누르세요.
> 그래도 막히면 `setup.bat`을 우클릭 → 속성 → 맨 아래 **"차단 해제"** 체크 → 확인 후 다시 실행합니다.

**이미 설치한 뒤에 `setup.bat`을 다시 실행해도 안전합니다.** 끝난 단계는 건너뜁니다. 설치 도중 실패했을 때 그냥 다시 실행하면 이어서 진행됩니다.

### 4단계. 실행

- **바탕화면의 "Raju's Converters" 아이콘을 더블클릭**하면 서버가 켜지고 브라우저가 열립니다(최대 40초 걸릴 수 있습니다).
- 또는 폴더의 **`web.bat`** 을 더블클릭합니다. 이 경우 검은 창이 남아 있고, **그 창을 닫으면 프로그램이 종료됩니다.**
- 브라우저 주소는 `http://127.0.0.1:8765` 입니다. 이 주소는 내 PC 안에서만 열립니다.

끝낼 때는 화면 오른쪽 위의 **서버 끄기**를 누르세요.

## 처음 사용할 때 알아 둘 것

**① 모델 내려받기 (처음 한 번)**
음성인식(Whisper)과 글자 인식(OCR)은 처음 쓸 때 모델을 인터넷에서 내려받고, 이후에는 인터넷 없이 PC에서 돕니다.

| 모델 | 크기 | 설명 |
|---|---|---|
| tiny | 약 75MB (실측) | 가장 빠름, 정확도 낮음 |
| base | 약 140MB | |
| **small** (기본) | 약 460MB | 속도와 정확도의 균형 |
| medium | 약 1.5GB | 한국어 설교·강의에 권장 |
| large-v3 | 약 3GB | 가장 정확하지만 CPU에서는 매우 느림 |
| 스캔 PDF 글자 인식 | 약 13MB | 한국어 모델 |

(`tiny` 외의 크기는 공개된 대략값이며 이 PC에서 모두 재어 본 것은 아닙니다.)
모델 파일은 음성인식 모델이 `C:\Users\내이름\.cache\huggingface`, 글자 인식 모델이 설치 폴더의 `.venv\Lib\site-packages\rapidocr\models`에 저장됩니다.

**② 변환 속도**
GPU는 쓰지 않고 CPU만 씁니다. 음성인식은 영상 길이의 1~2배(small 기준)가 걸립니다. 유튜브 영상에 자막이 있으면 음성인식 없이 몇 초 만에 끝납니다.

**③ 결과 파일 위치**
변환한 파일은 설치 폴더의 **`output`** 폴더에 자동으로 저장됩니다. 화면의 **저장 폴더** 버튼으로 바로 열 수 있습니다.

## 선택 설정

### 한글(HWP·HWPX) 변환 (선택)
**한글 변환** 탭에서 `.hwp`·`.hwpx`를 올리면 됩니다. PC에 **한컴오피스(한글)**가 설치되어 있으면 PDF·이미지·Markdown을, 없으면 Markdown만 바꿀 수 있고 화면이 이를 알아서 안내합니다.

- 변환 중 한글이 **보이지 않게** 열렸다 닫힙니다. 파일 하나에 10초 안팎입니다.
- 사용자가 직접 열어 둔 한글 문서에는 영향이 없습니다(별도의 한글을 따로 띄웁니다).
- 암호가 걸린 문서나 배포용(읽기 전용) 문서는 변환되지 않습니다.
- **한글에 "파일 접근을 허용하시겠습니까?" 창이 뜨면** 이 프로그램은 임시 폴더만 쓰도록 되어 있어 보통 뜨지 않습니다. 혹시 뜬다면 "허용"을 눌러 주세요. 3분이 지나도 응답이 없으면 알아서 중단합니다.

### Claude 요약·소제목 (선택)
Anthropic의 API 키가 있을 때만 쓸 수 있는 기능입니다. 키는 <https://console.anthropic.com/> 에서 발급합니다.

1. 설치 폴더에 **`.env`** 라는 이름의 파일을 만듭니다. (메모장으로 저장할 때 **파일 형식을 "모든 파일"**로 하고 이름을 `.env`로 지정하세요. 확장자가 `.txt`로 붙으면 안 됩니다.)
2. 내용에 한 줄을 적습니다.
   ```
   ANTHROPIC_API_KEY=sk-ant-여기에-내-키
   ```
3. 프로그램을 껐다가 다시 켭니다. 이제 영상 탭의 "Claude 요약·소제목" 스위치가 동작합니다.

`.env`는 GitHub에 올라가지 않습니다. 남에게 공유하지 마세요.

### '서버 시작' 버튼 (선택)
서버를 끈 뒤 같은 화면에서 다시 켜려면 한 번 등록해야 합니다. `setup.bat`에서 "예"를 고르거나, PowerShell에서 아래를 실행하세요. (현재 사용자에게만 적용되고 관리자 권한이 필요 없습니다.)

```
powershell -ExecutionPolicy Bypass -File register-protocol.ps1
```

처음 누르면 브라우저가 "앱을 열까요?"라고 묻는데 **"항상 허용"**을 체크하세요. 등록하지 않아도 바탕화면 아이콘으로 다시 실행하면 됩니다. 해제는 `unregister-protocol.ps1`입니다.

### 포트 바꾸기
8765번 포트가 다른 프로그램에 쓰이고 있다면 환경변수 `VOD_PORT`를 지정하고 실행합니다. 예: 명령 프롬프트에서 `set VOD_PORT=8800` 후 `web.bat`(브라우저도 그 포트로 열립니다).
포트를 바꾸면 바탕화면 아이콘과 `launcher.html`, '서버 시작' 버튼은 기본 포트(8765) 기준이라 맞지 않을 수 있으니 `web.bat`으로 실행하세요.

## 업데이트

폴더의 **`update.bat`을 더블클릭**하면 됩니다. 최신 프로그램을 받아 덮어쓰고(내 결과와 설정은 그대로), 필요한 프로그램을 갱신합니다. 실행 중이었다면 **서버 끄기** 후 다시 켜야 새 버전이 적용됩니다.

**유튜브 변환이 갑자기 실패하면** 먼저 `update.bat`을 실행해 보세요. 유튜브가 자주 바뀌어서 yt-dlp를 최신으로 유지해야 합니다.

## 삭제

1. 프로그램이 켜져 있으면 화면의 **서버 끄기**를 누릅니다.
2. 바탕화면의 **Raju's Converters** 바로가기를 지웁니다.
3. '서버 시작' 버튼을 등록했다면 `unregister-protocol.ps1`을 실행합니다.
4. 설치 폴더를 통째로 지웁니다. (변환 결과를 보관하려면 `output` 폴더를 먼저 옮기세요.)
5. 모델까지 지우려면 `C:\Users\내이름\.cache\huggingface` 안의 `hub\models--Systran--faster-whisper-*` 폴더를 지웁니다.

## 문제가 생겼을 때

| 증상 | 원인과 해결 |
|---|---|
| **"Python을 찾지 못했어요"** | Python을 설치하지 않았거나, 설치할 때 PATH 체크를 빠뜨렸습니다. Python을 다시 설치(또는 설치 파일 재실행 → Modify)해서 체크하고, 열린 창을 모두 닫은 뒤 `setup.bat`을 다시 실행하세요. |
| `python`을 입력하면 **Microsoft Store가 열림** | Windows의 가짜 별칭 때문입니다. 설정 → 앱 → 고급 앱 설정 → **앱 실행 별칭**에서 `python.exe`, `python3.exe`를 끄세요. |
| `setup.bat`이 **바로 닫힘** | 우클릭 → 관리자 권한이 아니라 **일반 실행**으로 다시 해 보세요. 그래도 같으면 명령 프롬프트에서 설치 폴더로 이동해 `setup.bat`을 입력하면 창이 안 닫혀 오류를 볼 수 있습니다. |
| **패키지 설치 중 오류**, 오래 걸림 | 인터넷 연결을 확인하고 `setup.bat`을 다시 실행하세요(받은 것은 건너뜁니다). 회사·학교 네트워크의 프록시나 보안 프로그램이 막는 경우가 있습니다. |
| 설치는 됐는데 **브라우저가 "연결할 수 없음"** | 서버가 켜지는 데 몇 초 걸립니다. 5~10초 뒤 새로고침하세요. 계속되면 `web.bat`으로 실행해 검은 창의 오류 문구를 확인하세요. |
| **포트 8765가 이미 사용 중** | 다른 프로그램이 쓰고 있습니다. [포트 바꾸기](#포트-바꾸기)를 보세요. |
| 화면에 **"서버가 꺼져 있어요"** 배너 | 서버가 종료됐다는 뜻입니다. 배너의 **서버 시작**(등록한 경우) 또는 바탕화면 아이콘으로 다시 켜면 화면이 자동으로 다시 연결됩니다. |
| **유튜브 변환 실패** | `update.bat`으로 yt-dlp를 갱신해 보세요. 비공개·삭제·로그인이 필요한 영상, 연령 제한 영상은 변환할 수 없습니다. 짧은 시간에 너무 많이 시도하면 유튜브가 잠시 막기도 합니다. |
| **음성인식이 너무 느림** | CPU만 쓰기 때문입니다. 모델을 `small`이나 `base`로 낮추거나, 자막이 있는 영상은 "자막 무시" 스위치를 끄세요. |
| 스캔 PDF 글자 인식이 **시작을 못 함** | 처음 한 번 모델(약 13MB)을 내려받아야 해서 인터넷이 필요합니다. |
| 한글 변환이 **"한글이 응답하지 않아 중단했어요"** | 한글에 확인 창(암호 입력, 보안 확인 등)이 떠서 막힌 경우입니다. 문서에 암호가 없는지, 한글이 정상적으로 열리는지 확인하세요. |
| 한글 변환 탭에서 **PDF·이미지가 회색으로 선택 불가** | 한컴오피스를 찾지 못한 것입니다. 한컴오피스를 설치한 PC에서 쓰거나 Markdown을 고르세요. |
| **백신이 경고** | 스크립트(`.bat`, `.ps1`)가 프로그램을 설치·실행해서 경고가 나올 수 있습니다. 소스는 모두 공개되어 있고 이 폴더 안에서만 동작합니다. 신뢰할 수 없다면 [고급: 직접 설치](#고급-직접-설치-macoslinux-포함)로 명령을 하나씩 확인하며 진행하세요. |
| 검은 창의 **한글이 깨져 보임** | 표시만 그런 경우가 많아 동작에는 영향이 없습니다. Windows Terminal에서 열면 정상으로 보입니다. |

## 고급: 직접 설치 (macOS·Linux 포함)

`setup.bat` 없이 직접 하는 방법입니다. **macOS·Linux는 시험해 보지 못했습니다.** 막히면 Issues에 남겨 주세요.

```bash
git clone https://github.com/byraju-hub/converters.git
cd converters
python -m venv .venv                          # macOS/Linux: python3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt     # macOS/Linux: .venv/bin/python -m pip ...
.venv\Scripts\python web.py                   # macOS/Linux: .venv/bin/python web.py
```

그다음 브라우저에서 `http://127.0.0.1:8765`를 엽니다. 서버는 `Ctrl+C`로 끕니다.
명령줄만 쓰려면 `python vod2md.py`, `python pdf2md.py`, `python pdftools.py`를 직접 실행할 수 있습니다(사용법은 README 참고).

## 개인정보와 동작 방식

- 변환은 모두 **내 PC에서** 일어나고 파일을 서버로 올리지 않습니다. 화면은 `127.0.0.1`(내 PC 안)에서만 열리며 같은 네트워크의 다른 사람은 접속할 수 없습니다.
- 인터넷에 접속하는 경우는 다음뿐입니다: 설치, 모델 내려받기, 유튜브 영상·자막 가져오기, 화면의 글꼴(Pretendard)과 업데이트.
- **Claude 요약을 켜면** 영상의 스크립트 텍스트가 Anthropic API로 전송됩니다. 켜지 않으면 전송되지 않습니다.
